# Krishil — portfolio

**I build the AI that runs my businesses. It does all my work while I sleep.**

My personal site: live products (Ovrix, Kaapo, God View, Ruby, Saathi), everything I've built, my story from robots to AI agents, how my agents run my day, and a terminal you can talk to.

- 3D hero in Three.js: an AI core with my businesses in orbit and data pulses running between them
- Smooth scrolling (Lenis) and scroll animations (GSAP)
- All content in `src/data.js`, so adding a project or a social is one edit

## Build

`npm install && npm run build` bundles `src/` into `public/` (Vercel does this on every push).

Designed and built by me, with AI.
